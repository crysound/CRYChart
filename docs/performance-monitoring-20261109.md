# 持续监视绘图性能优化

日期：2026-11-09。

本轮仅修改 CRYChart。
最终交付时，OpenTest 的业务源码和配置保持原样。
安装包的构建副作用已经恢复，详见下文。
桌面报告的 P01/P02 是本轮问题来源。

## 修复内容

默认的密集流式绘图原来只接纳 1 px 和 2 px 实线。
1.5 px 实线会回退到大量原始几何投影和提交。
同一负载下的真实 Chrome 检查复现了这个差异。

本轮允许符合条件的有限正线宽复用现有密集绘图缓存。
准入仍要求有界保留窗口和足够的物理像素密度。
透明线、虚线、面积和可见点标记继续使用原回退路径。
调用方无需启用实验选项。

绘图视图复用现有极值与邻点选择。
原始数据、坐标精度、游标查询和轴范围计算保持原数据入口。
通用视图的中心线分组上限为 0.5 个物理像素。
这个上限不等于抗锯齿结果逐像素相同。

普通兼容实线也可以共享一次真实的 WebGL 状态捕获。
状态只在本次同步绘制中共享，结束时恢复。
混合绘制、外部帧缓冲和不支持的属性保持原安全路径。
三组普通线的记录型 GL 检查中，查询次数从 55 降为 20。
这个调用计数不等于实际性能加速比例。

## 负载定义与纠正

现场统计中的 `series: 4` 不是四个采集通道。
另一个现场快照记录了两个活动主通道和两个空辅助系列。
每图 576 万样本对应两个主通道各保留 288 万样本。
在 48kHz 下，每个主通道的保留窗口为 60 秒。

本轮的主要复现包含九个图表。
两个重负载图表使用上述主通道和辅助系列结构。
X 列使用 Float64，原始 Y 和绘图 Y 使用 Float32。
映射保留 `xValues / yValues / renderYValues` 3 列结构。
每个宿主为约 463 × 119.55 CSS 像素。
设备像素比为 1.75，输入按 48kHz 的时钟持续追加。

其余七个图表保留报告中的图表级样本数量。
现场没有记录这些图表的逐系列分布和完整更新节奏。
主要复现将它们作为静态上下文。
另有九个图表共同刷新时的补充检查。
数据含确定性的尖峰与 NaN，不是实际设备录制数据。
原四通道 Float64 压力场景单独保留，不冒称现场结构。

## 修改前后实测

使用安装的前台 Chrome 156 和 AMD Direct3D11。
未使用无头浏览器或强制软件 GPU。
修改前后的库分别固定为旧 ESM 副本和新构建。
每轮先预热 1.2 秒，再观察 6 秒。
鼠标检查保留全部 24 个事件样本。

| 指标 | 修改前，1.5 px | 修改后，1.5 px |
| --- | ---: | ---: |
| rAF 间隔中位数 | 133.6 ms | 16.7 ms |
| rAF 间隔 P95 | 217.0 ms | 17.0 ms |
| 鼠标等待 P95 | 189.4 ms | 18.6 ms |
| 6 秒窗口的长任务数 | 32 | 0 |
| 每个重负载图表的原始保留量 | 5760000 | 5760000 |
| 结束快照中的提交样本统计 | 5760176 | 13811 |

rAF 间隔反映浏览器处理动画回调的节奏。
输入更新频率约为 50 Hz，不能把 rAF 频率当成设备采样率。
提交样本是渲染器统计，包含几何处理产生的额外项。
末帧计数不代表整个运行过程的固定值。

旧构建的 2 px 实线已能使用密集路径。
修改前后，这组检查的 rAF 中位数均约为 16.7 ms。
本轮收益主要来自解除 1.5 px 等线宽的非必要限制。

## 持续运行和画质检查

持续运行检查在第 1、5、10 分钟分别取样。
三个检查点的鼠标等待 P95 分别为 17.7、16.9、17.7 ms。
三个 6 秒采样窗口都没有长任务。
整段记录了 6 次偶发长任务，最长 403 ms。
整段长任务计数与每个采样窗口的计数分开报告。
偶发长任务不能省略成全程没有阻塞。

JS 堆使用量在三个检查点约为 127、146、194 MB。
这些快照没有强制垃圾回收，不能据此判断内存泄漏。
也不能宣称内存长期稳定或偶发卡顿已经全部消除。

九图共同刷新检查保留静态小图数据，每 20 ms 请求九图重绘。
它增加绘制请求，不冒称已恢复现场的小图数据更新节奏。
该检查中，鼠标等待 P95 从 213.2 ms 降为 16.5 ms。
6 秒观察窗口的长任务数从 30 降为 0。

尖峰和 NaN 检查使用固定数据比较密集视图与完整源几何。
像素邻域容差为 2 个物理像素，轴文字不计入断线区域。
同时检查原始样本、最近点查询、自动轴新峰值和固定范围。
完整源图像的 3136 个蓝色像素都在密集图像的容差邻域内。
单个尖峰的顶部位置差为 0，NaN 缺口保持为空。
自动轴跟随新增的 0.5 峰值，固定轴仍保持 -0.2～0.2。
