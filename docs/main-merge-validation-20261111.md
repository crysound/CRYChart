## 合并前发现的测试问题

首轮本地与 Windows CI 示例测试均为 41 个场景出图、11 项交互通过、2 项失败：

1. 百万采样检查只捕获 `drawArrays`，仍要求旧的 `2N` 顶点 strip。当前默认路径通过 coverage mask 的 `drawArraysInstanced(TRIANGLE_STRIP, 0, 4, N-1)` 提交全部相邻线段，再合成到数据画布。旧检查捕获的是最后的四顶点合成，误判为没有完整采样。
2. 场景目录页面已显示“演示场景”和四项“独立验证”，测试仍期待旧的“待验收”文案。

仅修正示例测试驱动，不改变图表源码或示例界面。检查同时保留旧 strip 路径，并验证 coverage 路径的起终点属性、完整线段数量、mask 与合成纹理身份；从实际 GPU 输入缓冲读取全部采样，与独立的原始公式逐点比较，再核对可见数据像素。目录检查保留未声称验收完成的语义。
